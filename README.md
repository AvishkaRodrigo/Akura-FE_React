# Education Institute Management System

##Features

5 user roles ( Admin | Teacher | Staff | Student | Parent )
- User management
- User registration 
- Online Payment gateways
- Class schedule & Management
- Uploade & Manage learning materials
- Online quizzes and assessment results
- Generate & Scan QR code (Student attendance tracking using QRcodes)
- Real-time notifications(Monitoring student performance and early leaving notifications)


##Technology Stack
`MERN stack`

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/akura-institute.git
cd akura-institute
```

2. Install backend dependencies:

```bash
cd backend
npm install
```

3. Install frontend dependencies:

```bash
cd ../frontend
npm install
```

4. Create a `.env` file in the backend folder and add your MongoDB connection string and other environment variables:

```
MONGO_URI=<your_mongodb_connection_string>
JWT_SECRET=<your_jwt_secret>
PORT=5000
```

5. Run the backend server:

```bash
cd ../backend
npm start
```

6. Run the frontend server:

```bash
cd ../frontend
npm start
```

7. Open the application at `http://localhost:3000`
